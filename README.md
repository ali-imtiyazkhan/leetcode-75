# 🚀 LeetCode 75 – Pattern-Based DSA Practice

This repository contains my solutions to **75 carefully selected LeetCode problems**, solved in a structured and pattern-oriented approach.

The goal of this repository is to:

- Strengthen Data Structures & Algorithms fundamentals
- Master common interview patterns
- Improve problem-solving speed and clarity
- Prepare for coding interviews efficiently

---

## 📚 Approach

Instead of solving problems randomly, this repository is organized **topic-wise and pattern-wise**.

Each problem is categorized under a specific concept such as:

- Sliding Window
- Two Pointers
- Hash Map / Set
- Binary Search
- Stack
- Queue
- Recursion
- Backtracking
- Dynamic Programming
- Trees
- Graphs
- Prefix Sum
- Greedy

This makes revision easier and builds pattern recognition.
